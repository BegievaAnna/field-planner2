# Планировщик выездных работ: [Зелёная зона - Москва/Санкт-Петербург]

## Для кого и зачем
[Для организатора учебного обследования зелёной зоны в Москве или Санкт-Петербурге. Задача — подготовить план выезда, отметить пункты подготовки и при необходимости распечатать отчёт. Три вида работ:
- `green` — обследование зелёной зоны;
- `water` — наблюдение у водоёма;
- `ice` — исследование водоёма в зимний период.
Дополнительное условие: «рядом есть водоём» (`nearWater`).]

## Сценарии
1. Создать план.
2. Заполнить чек-лист и получить сводку.
3. Открыть сохранённый план, изменить и распечатать.

## Данные и источники
[- Первая практическая: карточка риска «Гололёд» — https://begievaanna.github.io/risk-card1/
- Панель безопасности (MET Norway): https://begievaanna.github.io/safety-dashboard/
- API: MET Norway Locationforecast 2.0, `https://api.met.no/weatherapi/locationforecast/2.0/compact`, без ключа.
- S1 — МЧС России, памятка о полевых работах (проверено 2026-11-13).
- S2 — МЧС России, правила безопасности у воды (проверено 2026-11-13).
- S3 — МЧС России, безопасность на льду (проверено 2026-11-13).
- S4 — МЧС России, правила поведения в гололёд (проверено 2026-11-13).]

## Запуск
Открыть папку в VS Code и index.html через Live Server.

## Ограничения
Учебный инструмент подготовки, не разрешение на проведение работ.  
Планы сохраняются только в этом браузере (localStorage).  
Текущие данные API не являются прогнозом на дату выезда.

## Результаты проверки
- Сохранение и открытие двух планов работают; отметки и данные формы восстанавливаются.
- Ошибка API (отключённая сеть) показывает понятное сообщение, чек-лист и планы продолжают работать.
- Пустое хранилище — корректное пустое состояние.
- Повреждённые данные показывают ошибку и требуют подтверждения перед перезаписью.
- Печать формирует отчёт по текущей форме и отметкам; фон не печатается.
