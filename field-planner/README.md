# Планировщик выездных работ: [Зелёная зона]

## Для кого и зачем
[Для организатора учебного обследования зелёной зоны. Задача — подготовить план выезда и отметить пункты подготовки. Два вида работ: обследование зелёной зоны (`green`) и наблюдение у водоёма (`water`). Дополнительное условие: «рядом есть водоём»(`nearWater`).]

## Сценарии
1. Создать план.
2. Заполнить чек-лист и получить сводку.
3. Открыть сохранённый план, изменить и распечатать.

## Данные и источники
[Материалы первой практической: карточка риска «Гололёд» и панель безопасности (MET Norway).  
API второй практической: Open-Meteo, документация `https://open-meteo.com/en/docs`.  
Источники: S1 — МЧС России, памятка о полевых работах, проверено 2026-11-13; S2 — МЧС России, правила безопасности у воды, проверено 2026-11-13.]

## Запуск
Открыть папку в VS Code и index.html через Live Server.

## Ограничения
Учебный инструмент подготовки, не разрешение на проведение работ.
Планы хранятся в этом браузере. Сведения API имеют своё время и место.
